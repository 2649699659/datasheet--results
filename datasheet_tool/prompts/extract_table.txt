## Field Definitions

- **symbol**: Standard parameter symbol (e.g., "RDS(on)", "VGS(th)", "QG", "Eoff")
- **name**: Full English parameter name (e.g., "Drain-Source On Resistance")
- **value**: Single value (for single-value tables)
- **min/typ/max**: Separate values (for min/typ/max tables)
- **unit**: Physical unit (V, A, mΩ, nC, °C, ns, etc.)
- **condition**: Test conditions (e.g., "VGS=18V; ID=300A; TC=25°C")
- **page**: Page number where parameter was found
- **table_index**: Table index on that page
- **row_index**: Row index in the table (0-indexed, header=0)
- **source_text**: Original table row text for reference
- **confidence**: Your confidence score (0.0 to 1.0)
- **needs_review**: true if uncertain about any field

## Extraction Rules

1. **Extract ALL parameters** including:
   - Voltage ratings: VDS, VGS, VCES, VRRM, V(BR)DSS, VGE(th), VCE(sat)
   - Current ratings: ID, IC, IFSM, ICRM, IDM
   - Resistance: RDS(on), Ron, Rg
   - Capacitance: Ciss, Coss, Crss, Cies, Coes, Cres
   - Gate charge: QG, QGS, QGD, QGE, Qrr
   - Switching times: td(on), tr, td(off), tf, trr, tdon, tr, tdoff
   - Energy: Eon, Eoff, Ets, ERR
   - Thermal: RthJC, RthCH, Tj, Tstg, Tvj
   - Mechanical: Mounting torque, dimensions, weight
   - Isolation: Visol, Viso, clearance, creepage

2. **For each parameter**:
   - Extract all available values (min/typ/max)
   - Normalize condition format: "VGS=18V; ID=300A; TC=25°C"
   - Use null if value not available (not string "null")

3. **Condition normalization**:
   - VGS=-5/+18V (not VGS=-5V or VGS=+18V separately)
   - TC=25°C or TJ=25°C or Tvj=25°C
   - ID=300A, VDD=1200V, VR=600V

4. **Module type**: Identify from description or part number:
   - "Half-Bridge", "Sixpack", "PIM", "Chopper", "Single Switch"
   - "SiC MOSFET", "IGBT", "CoolMOS"

5. **Manufacturer**: Look for company name in header/footer
   - "Infineon", "Wolfspeed", "Mitsubishi", "ON Semiconductor", "STMicroelectronics"

6. **Confidence scoring**:
   - 0.95-1.0: Clear table, unambiguous values
   - 0.80-0.94: Normal extraction
   - 0.60-0.79: Some uncertainty (merged cells, unclear headers)
   - <0.60: Major issues, set needs_review=true

7. **needs_review=true** when:
   - Confidence < 0.8
   - Missing unit but has value
   - Ambiguous table structure
   - You cannot determine min/typ/max vs value column
   - Parameter name unclear
